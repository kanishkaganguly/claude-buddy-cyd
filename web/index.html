Flash your CYD Claude Buddy

Firmware and the Clawd animations, written straight from this page over USB. Nothing to install.

  1. Plug the ESP32-2432S028R (CYD) into this computer with a USB data cable.
  2. Click Connect, pick the USB Serial port (the board's CH340 chip), then choose Install CYD Claude Buddy and confirm.
  3. Wait for Installation complete (a minute or two), then close the dialog so the USB port is free again.
  4. If you came here from ./install.sh, go back to the terminal and press Enter.
This browser can't talk to USB devices. Open this page in Chrome or Edge on a desktop computer (Firefox and Safari have no Web Serial).
Web Serial only works on a secure page. Open it from http://localhost (that's what ./install.sh does) or over https://.

Updating a buddy you already set up? Leave Erase device unchecked. That keeps its pairing token, touch calibration and usage history, so nothing on your computer needs to change.

If it doesn't work

  • No port in the list: try another cable (many are charge-only). On Linux your user must be in the dialout group. A running buddy bridge holds the port; ./install.sh flash stops it first.
  • Stuck on "Connecting" or "Preparing installation": hold the board's BOOT button, start again, and let go once writing starts.
  • White or garbled screen after flashing: your panel isn't the ILI9341 this build targets; see Building from source in the user guide.
